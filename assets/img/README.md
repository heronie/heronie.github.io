# 照片放这里

> 当前 `portrait.jpg` 已从简历中的照片提取，处理为 4:5 黑白竖构图（800×1000，约 95KB）。
> 要换照片，直接覆盖同名文件即可。

把照片命名为 `portrait.jpg` 放进本文件夹，页面会自动换上，不用改任何代码。

## 要求

- 文件名必须是 `portrait.jpg`（全小写）
- 正方形最好，或者人物居中的竖图；页面按圆形裁切
- 建议 600×600 以上，文件控制在 300KB 以内（手机加载快）
- 只用你自己的照片，不要用网图

## 没有照片时会怎样

页面显示一枚赭石色的「冯」字印章占位，不会破版、不会出现裂图图标。
所以你可以先上线，之后再补照片。

## 换成 png 也可以

如果你的文件是 png，把 `site/index.html` 里这一行的扩展名改掉即可：

```html
<img src="assets/img/portrait.jpg" alt="Hero 冯生" onerror="this.classList.add('miss')">
```
